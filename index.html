Como mudar de computador

  1. Clique em Exportar backup completo.
  2. Copie o ficheiro HTML, as fotos e o ficheiro de backup para o novo computador.
  3. Abra o HTML no novo computador.
  4. Entre em Backup / Importar e carregue o ficheiro JSON.
